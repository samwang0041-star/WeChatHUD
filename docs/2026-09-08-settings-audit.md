# 设置与联系人可靠性审计（2026-09-08）

范围：`ContactsSettingsView`、`WhitelistScanView`、`AIWhitelistCategorizer`、`RelationshipInferrer`，以及本次新增的失败路径与事务回归测试。

## 已修复并有测试证据

- 联系人新增、级别变更、删除、编辑保存都检查持久化错误。失败时保留当前界面状态并显示错误；编辑窗口只有联系人和关系画像字段都成功保存后才 `dismiss()`。
- 联系人编辑的联系人表、白名单追踪和关系画像用户字段现在处于同一个外层事务；任一写入失败会整体回滚，表单保持打开。
- 删除联系人增加确认提示，明确只删除 WeChatHUD 的追踪、画像和处理状态，不删除微信聊天记录。
- 关系画像 AI 成功但 SQLite 写入失败时返回 `nil`，调用方不会把未落盘的画像当成成功结果；旧画像保持可读。
- 批量白名单分类返回批次状态：合法空数组是成功但没有建议；空响应、HTTP 错误、无效 JSON 都记为失败；多批次可显示部分成功和失败数量。
- 扫描状态文案已修正为真正的 Swift 字符串插值，不再把 `(count)` 当作字面量显示；无候选、无最近消息、全失败、部分失败和无建议都有不同状态。
- 联系人来源优先刷新微信联系人索引，索引为空时回退到最近会话，并过滤明显的系统/服务账号。
- 添加联系人候选读取失败会显示可理解的原因和“重试读取”，不会把读取错误伪装成空列表；索引为空时仍可使用最近会话回退。
