# WeChatHUD Context Superpowers Roadmap

日期：2026-04-12

## 目标

把 WeChatHUD 从“消息提醒层”继续推进成“微信工作理解层”。

核心判断：

- 微信原生擅长“告诉你有消息”
- WeChatHUD 更该擅长“告诉你刚刚发生了什么、为什么轮到你、你现在最该做什么”

这类能力的共同底座不是单个功能，而是一条统一链路：

1. 从本地微信 DB 抓消息窗口
2. 识别当前锚点消息
3. 打包为结构化上下文
4. 交给本地 OMLX / OpenAI-compatible 模型做语义解释
5. 返回短、硬、可执行的结论
6. 落缓存、落审计、支持人工反馈

今晚先落的功能是 `什么情况`，它会成为这条链路的第一个产品化入口。

## 已落地能力

### 1. `什么情况`

触发条件：

- 群聊
- 在白名单里
- 明确 @ 你

入口位置：

- 顶部通知 banner
- hover 展开的 VIP 消息行

点击后输出四段：

- 发生了什么
- 为什么 @ 你
- 当前状态
- 下一步

系统行为：

- 优先走本地 OMLX AI 分析
- 成功结果写入 `analysis_cache`
- 调用过程写入 `ai_audit`
- AI 不可用时自动退化到本地启发式兜底

这意味着后面大部分“上下文理解”能力都已经有了第一版基础设施。

## 最值得继续做的 8 个功能

### P0: 直接提升每天决策速度

1. `我该回什么`

- 入口：`什么情况` card 底部再加一个按钮
- 输出：一条建议回复 + 两条备选语气
- 价值：从“知道发生了什么”进一步缩短到“可以马上回”

2. `现在轮到谁`

- 入口：群聊卡片 / 项目 lane 卡片
- 输出：当前 owner、下一棒是谁、有没有明确 deadline
- 价值：减少在群里重新翻“到底谁在跟”

3. `这事定了吗`

- 入口：群聊和项目主线
- 输出：已定 / 未定 / 看起来已定但没人明确收口
- 价值：解决微信群里最常见的“聊过了但没结论感”

4. `一句话补课`

- 入口：进入群聊前
- 输出：自上次打开以来的单句进展
- 价值：快速回到上下文，不重新阅读 30 条消息

### P1: 让微信变成工作推进面板

5. `上次我答应了什么`

- 入口：私聊 / 群聊顶部 briefing
- 输出：最近一次你明确答应的事项、时间点、是否已兑现
- 价值：减少“我记得我说过要发什么，但忘了”

6. `相关文件在说什么`

- 入口：文件消息旁 / brief card
- 输出：文件大意、与当前话题的关系、需要不需要你处理
- 价值：微信群文件很多，但真正有用的很少

7. `风险升级`

- 入口：reply debt / 待回账本
- 输出：连续 @、连续催促、多人围观、出现 deadline 时自动升档
- 价值：把“普通未回”与“快出事的未回”分开

8. `项目主线`

- 入口：detail panel 独立 tab
- 输出：跨私聊和群聊的 lane，总结最近进展、卡点、下一动作
- 价值：真正脱离“按聊天组织”的微信原生心智

## 建议的实现顺序

### Phase 1

- `什么情况`
- `我该回什么`
- `风险升级`

原因：

- 都能复用同一份上下文窗口
- 离当前 HUD 形态最近
- 对每天使用频率影响最大

### Phase 2

- `现在轮到谁`
- `这事定了吗`
- `一句话补课`

原因：

- 开始从“理解一条消息”扩展到“理解一段推进关系”

### Phase 3

- `上次我答应了什么`
- `相关文件在说什么`
- `项目主线`

原因：

- 需要更强的跨消息、跨文件、跨聊天聚合
- 但一旦做起来，产品价值会明显高于普通微信插件

## 架构建议

### 不要做成一堆孤立 AI 按钮

建议形成统一模块：

- `ContextWindowBuilder`
- `ContextBriefingService`
- `ActionSuggestionService`
- `DecisionStateService`
- `ContextAudit + Feedback`

这样每个新功能只是：

- 同一份上下文
- 不同 prompt
- 不同结果 schema

而不是每个按钮都重新拼消息、重新请求、重新缓存。

### 分层原则

- 事实层：继续走确定性逻辑
- 理解层：交给本地 OMLX
- 呈现层：结果必须短、硬、可执行
- 评估层：审计 + 用户反馈，别靠感觉判断 AI 是否有用

## 验收标准

一条“上下文理解”类功能是否值得保留，看三件事：

1. 用户是否比以前更少打开微信群翻历史
2. 输出是否能在 5 秒内帮助做决定
3. 错误时是否可审计、可反馈、可回滚

如果做不到这三点，就不是 superpower，只是把摘要换了个壳。
