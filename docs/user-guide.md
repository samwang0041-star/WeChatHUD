# WeChatHUD 使用指南

WeChatHUD 是 macOS 菜单栏与浮窗助手。从你选中的微信对话里整理待回、待办、承诺和草稿。默认不自动发送。AI 可选。

## 开始前

需要一台 macOS 14 或更新版本的 Apple 芯片 Mac，并在这台 Mac 安装、登录微信。把发行包里的 WeChatHUD 拖入“应用程序”后打开。第一次打开会进入设置向导，大约 3 分钟。

## 第一次连接

1. 先打开并登录微信，再点“连接微信”。系统打开授权窗口时，直接点“允许读取”，不用自己找文件夹。
2. 有的 Mac 还需要一次本机读取准备，大约 1–2 分钟。微信可能会关闭，你重新打开并登录即可；聊天记录不会被改动。出现“微信已连接”和更新时间才算完成。
3. 在向导里选择一个 AI 服务（可选）并测试连接，再点选一个要关注的联系人或群聊。没有 AI 也能看原文；摘要和回复草稿需要可用的 AI。

平时在“连接与数据”可以查看更新状态；更换账号时点击“更换微信账号”。不同账号的资料各自保留。

发送或跳转微信时，macOS 可能要求辅助功能权限。按应用提示打开系统设置，允许 WeChatHUD 后继续操作即可。

## 配置 AI

打开“AI 与提醒”，从预设供应商中选择（DeepSeek、Kimi、智谱等），或填入自定义服务。没有 AI 也可以读取微信原文和使用基础收件箱；消息摘要、回复建议以及需要 AI 的上下文整理必须有可用的 AI 服务。每个服务需要接口地址（预置服务会自动填写）、模型名称，以及服务方要求的 API Key。填写后点击“测试连接”；测试请求只发送测试文本，不包含聊天记录。

DeepSeek 可直接选择 `deepseek-v4-flash`（Flash）；接口地址为 `https://api.deepseek.com`，填写自己的 API Key 后测试连接。模型名以[DeepSeek 官方文档](https://api-docs.deepseek.com/quick_start/pricing/)为准。

API Key 必须由对应服务方提供。你需要在服务方的官方控制台自行注册、完成可能的实名认证或计费设置、创建密钥并确认模型权限与额度。WeChatHUD 不能代办注册、绕过地区或额度限制，也不能保证第三方服务长期可用。自定义接口只要兼容 OpenAI 风格的聊天接口就可以尝试，但地址、证书、鉴权方式和数据留存规则由该服务方负责。

“OpenAI Codex (ChatGPT 订阅)”使用这台 Mac 上 Codex 的登录状态，不在 WeChatHUD 中填写 API Key。必须先在本机完成 Codex 登录，且当前登录状态和订阅有权使用所选模型；登录失效、模型不可用或服务拒绝请求时，请回到 AI 设置查看测试结果。

## 日常工作流

- “今天”优先列出需要回复、@提醒和需要推进的消息。打开卡片可以查看摘要、原文和上下文，之后选择回复、稍后提醒或标记已处理。
- 群聊中的 @提醒可以打开“什么情况”，查看发生了什么、为什么提到你、当前状态和下一步。AI 结果会显示来源和置信度，低置信度内容应回到微信原文核对。
- “我的承诺”按进行中、超期、已完成和全部筛选。每条承诺保存来源原话、背景和下一步；识别结果用于整理，不等于事实证明。
- 在对话详情中生成或编辑回复后选择“存为草稿”。“回复草稿”可以继续编辑、保存修改、复制回复或回到对话。草稿不会自动发送。
- “AI 与提醒 → 浮窗提醒”可以分别开关群里 @ 我的消息、重要联系人消息和关注对话的普通更新，并设置浮窗展示时间。鼠标移入后可以继续阅读和操作；承诺到期等系统通知由 macOS 通知设置管理。
- 对话详情的“发送”会先让你确认收件人和内容，再通过微信操作并检查发送回执。若账号、窗口或权限校验失败，草稿应保留；请在微信中核对后避免重复发送。

## 从洞察继续回复

洞察详情先显示对话结论和建议。点击“查看对话与回复”可以打开最近的消息与回复框；查看历史日期时，该按钮也会进入当前对话，不会自动发送。

写到一半可以存为草稿，在“回复草稿”中继续编辑。点击“继续回复”会把选中的草稿带回回复框；如果回复框里已有其他文字，助手会先让你确认是否替换。发送仍需要单独确认。草稿列表里的删除只移除选中的草稿，不会删除微信消息。

## 自动托管

“自动托管”与回复草稿是两项不同能力。托管开关默认关闭；关闭时不会由定时队列自动发出，托管产生的待发送项需要在“托管记录”中人工查看、编辑、发送或取消。开启后，系统会按托管设置、排除联系人、信心阈值、频率限制和消息合并窗口处理低风险私聊，并在“托管记录”中留下处理结果。关注对话决定工作台的持续关注范围，托管还有自己的处理范围；不要把两者当成同一个开关。

群聊消息当前只记录，不自动发送回复。涉及转账、红包、小程序、密码、验证码、合同等敏感内容，或者无法确认目标会话、账号和发送结果时，不应把自动托管当成安全替代。开始使用时建议只选择少量对话，先观察记录，再决定是否扩大范围。

## 数据边界

微信源数据库按只读方式读取和解密；应用自己的设置、关注范围、草稿、分析结果和缓存保存在本机。启用 AI 后，相关消息片段、摘要和上下文会发送给当前所选 AI 服务。线上服务通常位于本机之外；自定义地址也可能指向远程服务器。

API Key、解密密钥和 OAuth 登录状态都应只保留在自己的 Mac 和官方工具中。不要把密钥写进截图、日志、工单或提交到代码仓库。遇到服务错误时，优先查看脱敏后的连接结果和服务方控制台，不要把密钥粘贴给他人排查。

## 排障顺序

### 没有消息或同步时间不更新

确认微信已登录，再打开“连接与数据”，按照当前显示的按钮继续。连接正常时可以点击“检查更新”。

系统授权窗口已经定位微信资料时，直接点击“允许读取”即可，无需填写位置。若没有找到聊天，请先打开微信并确认已登录，然后重试。

### AI 测试失败

确认当前服务、接口地址、模型和 API Key。预置服务的模型列表可以重新获取；自定义服务需要自行确认兼容接口、证书和额度。连接测试通过只代表测试请求成功，不代表每段聊天上下文都能被服务接受。

### 无法打开微信或发送

确认微信窗口存在且登录了正确账号，再检查辅助功能权限。发送键必须与微信设置一致：默认微信通常是 `Enter` 换行、`⌘Enter` 发送；如果你改成了 `Enter` 发送，请在自动托管设置中同步选择。任何“已提交但尚未确认”的结果都应回到微信核对，避免重复发送。

### 关注范围或账号不对

在“关注的对话”搜索并调整联系人级别；切换微信账号后重新确认目录和数据隔离状态。旧版资料若没有明确账号归属，不会自动绑定当前账号；只有在核实目录后才应使用设置里的显式绑定流程。

## 快捷键

工作台或浮窗处于当前应用时，可以使用对应的应用菜单快捷键；`Esc` 用于浮窗收起：

| 快捷键 | 操作 |
| --- | --- |
| `⌘1` | 打开助手工作台 |
| `⌘,` | 打开连接与数据设置 |
| `Esc` | 收起浮窗 |

菜单栏还提供显示/隐藏 HUD、刷新、打开复盘和退出。快捷键与菜单实际行为以当前版本为准。
